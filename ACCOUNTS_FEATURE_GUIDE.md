## Quick Start

### 1. Install Dependencies (Already Done)
```bash
npm install @supabase/supabase-js
```

### 2. Setup Supabase Database
Follow the instructions in `SUPABASE_SETUP.md` to:
- Create the accounts table
- Set up Row Level Security
- Get your Supabase credentials

### 3. Configure Environment
```bash
copy .env.template .env
```
Then add your Supabase URL and anon key to `.env`

### 4. Start the App
```bash
npm start
```

## Features

### ✅ View Accounts
- Displays all accounts from Supabase
- Shows loading state while fetching
- Displays "No accounts found" when empty

### ✅ Add Account
- Click "Add New" button
- Fill in first name, last name, and email
- Data is saved to Supabase
- Success notification appears

### ✅ Delete Account
- Click trash icon on any account
- Confirmation modal appears
- Account is deleted from Supabase
- Success notification appears

## Data Structure

```javascript
{
  id: UUID,              // Auto-generated by Supabase
  first_name: string,    // Required
  last_name: string,     // Optional
  email: string,         // Required, unique
  avatar: string,        // URL to avatar image
  created_at: timestamp, // Auto-generated
  updated_at: timestamp  // Auto-updated
}
```

## Troubleshooting

### "Cannot read properties of undefined"
- Make sure `.env` file exists with correct Supabase credentials
- Restart the development server after adding `.env`

### "Failed to add account"
- Check Supabase dashboard for errors
- Verify RLS policies are set correctly
- Check browser console for detailed error messages

### Accounts not loading
- Verify Supabase URL and key are correct
- Check network tab in browser dev tools
- Ensure accounts table exists in Supabase
